## Handoff boundary

Installer exchange/callbacks, metrics ingestion, ML execution, and Gemini chat are not implemented here. Agent-owned telemetry consumers return real empty/unavailable states until those systems satisfy [User Implementation Integration Contract](User%20Implementation%20Integration%20Contract.md).
