# Infra Monitor Development Lab Report

This LaTeX project is a concise report styled after the CUET report at
`../SWD_Final_Report.pdf`. The reference was used for layout only; its ClubHub
project content was not reused.

## Build

From this directory, compile `main.tex` twice with pdfLaTeX so the contents
page and references resolve:

```text
pdflatex main.tex
pdflatex main.tex
```

The report uses only local assets in `assets/`. It is written for A4 paper,
12-point serif text, and 1.15 line spacing. The course title, semester/session,
and submission date are left as `[TO CONFIRM]` rather than inferred.

Before submission, verify the team contribution wording, fill the marked
course details, run the documented project tests, and update any report
statements that change with the final code.
