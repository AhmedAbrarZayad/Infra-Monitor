\chapter{UI Screenshots}\label{app:screens}

All screenshots were captured from the Infra Monitor Flutter application
running on Android during project evaluation in November 2026.  Screens are
grouped by feature area and read left to right; each caption names the screens
and the use cases they serve.  \Cref{sec:gui} in Chapter~5 describes the
interface design in more detail.
